# Reconciling Gamma supplier earnings

1. Reconcile measured, successful calls by immutable call ID against the vendor account. The ask is the supplier's price; the platform spread is excluded from the supplier's accrual. Use [the usage-epoch accrual query](../scripts/tool_market_accruals.sql).
2. After an epoch closes, the issuer can target earlier settled charges using the available SN71 miner emission after **all** collection quotes. It prices the emission using the existing finalized-boundary valuation. A newly settled call from an older usage epoch is included on the next eligible pass. Suppliers are considered in the order of their oldest uncovered charge. Shortfalls, unregistered suppliers, and amounts below the conservative weight quantum remain unscheduled.
3. An accepted signed state reserves its target once. The miner statement reports amounts accrued, scheduled and unscheduled in micro-USD. An operator can inspect the exact epoch, state hash, valuation, recipient, target amount and count of matching gateway reveal reports using [the epoch target query](../scripts/tool_market_epoch_targets.sql).
4. Verify each reported commitment and reveal against the finalized chain, then inspect the actual `IncentiveAlphaEmittedToMiners` event and UID ownership at the relevant distribution block. Consensus, registration churn, rounding and prices affect received alpha. The event shows total miner incentive. It does not assign each unit of alpha to a specific tool call or distinguish other earnings for a shared UID. The statement leaves `realized_alpha_rao` unknown.

**Missing or disputed delivery.** A missing report can mean a missing acknowledgment of a successful reveal. The signed amount remains reserved against its original epoch for investigation. The software neither marks it paid nor schedules it twice. It has no automatic release of that reservation and no guarantee of a fiat-equivalent minimum. An exceptional reallocation would require independent finalized evidence, a rule for attributing actual incentives where several revenue sources share a UID, and an audited resolution preserving the original target.
